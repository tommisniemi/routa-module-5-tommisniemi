## In the loop

Read `plan.md` and `brain/`. Pick the first step that isn't done. If all are done and the verify skill reported a problem, pick the step that fixes it. Say in a few lines what to build next and which files it touches. Don't write code.

## A new tool

Check the running test environment for what the tool touches, and add what you find to `brain/project.md`. Draft the steps from `client/`. Ask the user about the decisions that matter, your recommendation first. Then write the steps into `plan.md`. Don't write code.
