# Routa identity MCP server

An MCP server for Routa's identity platform, so IT can configure it by asking. The project brain is in `brain/`. Routa's files are in `client/`.

- Build through the loop: the plan, build and verify skills in `.claude/skills`.
- Follow `client/conventions.md`.
- Start the test environment with `npm run test-environment`. The tokens are in `ROUTA_TOKEN` and `ROUTA_READONLY_TOKEN`.
