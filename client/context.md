# Context for the MCP server

## Who uses it

Routa's IT team: Tuomas and two administrators. They use Claude Code and know the platform well. Everyone else at Routa reads only, with a read-only token, to answer "who can reach what?".

## What good looks like

- Asking is enough: IT doesn't need to know the API's field names.
- Before anything changes, IT sees it in plain words: which group gains or loses which application, and which policy goes from what to what.
- Saying yes applies exactly what was shown, nothing else.
- A read-only token gets a clear refusal when it tries to change something, and nothing changes.
